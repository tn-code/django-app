Apllication Overview

An offline integrated management application designed for personal use.

Development System Overview

  • Project designing based on MTV architecture using Django, one of Python web frameworks
  • Server-assisted client side caching with Redis, a type of NoSQL that stores data with key-value structure
  • Style coding with SASS(Scss), a CSS preprocessor, to organize codes in better visibility and efficiency
  • Bootstrap, a CSS framework, for grid system, responsive mobile design and dynamic interactive DOM handling with built-in jQuery
  • Data manipulating with third-party APIs including News API
  • Object-oriented database handling using O/R mapper
  • Matplotlib for plotting graphs and charts along with database
  • Vue.js for interactive SPA-based client-side rendering as well as async requests with Axios
