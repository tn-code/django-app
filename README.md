# Multi-Domain Django App (Portfolio Project)

## 📜 Background
This project was initially developed as a portfolio piece during an earlier phase of my learning journey.  
It was designed to demonstrate full-stack skills using Django and various data processing techniques.  
Although it was initially used locally, the code remains a representation of my early exploration in creative, data-driven development.  
Now, I'm revisiting it as a record of past experience and a foundation to build on with newer technologies like NLP.

## 📝 Overview
This project is a multi-domain web application built with Django, with selective use of Vue.js for interactive components on specific pages.  
It integrates various APIs (such as Spotify and NewsAPI), utilizes Redis for efficient caching, and applies matplotlib for comprehensive data visualization.

## 🔧 Features

| Category                 | Feature             | Description                                                                 |
|--------------------------|---------------------|-----------------------------------------------------------------------------|
| Learning & Productivity  | Language Learning   | Vocabulary tracking, grammar examples, and customizable templates           |
|                          | ToDo & Schedule     | Tools for managing daily tasks and productivity                             |
| Media & Culture          | Music Analysis      | Chart visualization and statistics using the Spotify API                    |
|                          | Library System      | Manage book records and curated quotes                                      |
|                          | Blog & Diary        | Lightweight content management for journal-style entries                    |
| Daily Life               | Culinary Hub        | Seasonal ingredient suggestions, recipe logging, and dish management        |
|                          | Pharmacy            | Track pharmaceutical data and personal medicine information                 |
| Creative & Informational | Art Archive         | Track exhibitions, artists, and artwork metadata                            |
|                          | News Collector      | NewsAPI integration with curated feeds across multiple countries            |
| Utilities                | Visualization       | Graphs and charts with matplotlib                                           |
|                          | API Integration     | Use of external APIs like Spotify and NewsAPI                               |
|                          | Cache Control       | Automated data refresh with custom cache scheduling                         |
